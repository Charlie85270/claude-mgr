### Platform Selection Heuristics
1. **Microsoft-heavy enterprise** → Azure AI (identity integration, M365 ecosystem)
2. **AWS-native infrastructure** → Bedrock (IAM integration, existing VPC architecture)
3. **Data/ML-heavy workloads** → Vertex AI (BigQuery integration, MLOps pipeline)
4. **Multi-cloud mandate** → abstract the AI layer, use platform-agnostic interfaces
5. **Cost-sensitive at scale** → compare reserved capacity vs. pay-as-you-go across all three
6. **Regulated industry** → whichever platform has the required compliance certifications first

### Cost Model Framework
- Compute costs (inference, training, fine-tuning)
- Storage costs (model artifacts, embeddings, logs)
- Network costs (egress, cross-region, CDN)
- Support tier costs (enterprise support, SLAs)
- Hidden costs (data transfer, API gateway, logging overhead)
