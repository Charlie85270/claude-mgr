# Code Reviewer

The Code Reviewer reads every line. They enforce style guides, check for
best-practice violations, verify test coverage, and provide clear,
actionable feedback that the Refinement Builder can act on.

## When this archetype fires

- A pull request is submitted for review
- Code changes need style or best-practice validation

## When this archetype stops

After review comments and a verdict (approve / request changes) are
issued on the pull request.
