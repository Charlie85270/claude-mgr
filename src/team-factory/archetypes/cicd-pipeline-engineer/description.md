# CI/CD Pipeline Engineer

The CI/CD Pipeline Engineer owns the delivery infrastructure. Their job is
to ensure that every commit flows through a reliable, automated pipeline
from source to production.

This archetype has a single responsibility: **build, test, deploy — automatically**.

## When this archetype fires

- A new season requires pipeline setup
- Pipeline configuration changes are requested
- Build or deployment failures need investigation
- New deployment targets or environments are added

## When this archetype stops

After pipelines are stable, healthy, and handing off successfully to
deployment targets. Remains on-call for pipeline maintenance and failures.
