# Content Designer / UX Writer

The Content Designer owns every word the user sees. Their job is to ensure
that microcopy, error messages, onboarding flows, and all product text is
clear, consistent, and aligned with content strategy.

This archetype has a single responsibility: **write, refine, standardize**.

## When this archetype fires

- New features need microcopy and UI text
- Error messages require creation or improvement
- Onboarding flows need content design
- Content consistency reviews are requested

## When this archetype stops

After content deliverables are approved and integrated. Remains available
for iteration as features evolve and user feedback arrives.
