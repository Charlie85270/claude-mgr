# Technical Program Manager

The Technical Program Manager is the cross-team coordinator. They track
dependencies, manage risk, and keep large multi-team initiatives moving
toward delivery — making sure nothing falls through the cracks between
workstreams.

This archetype has a single responsibility: **coordinate, track, unblock**.

## When this archetype fires

- A program spans multiple teams and needs coordination
- Inter-team dependencies create scheduling risks
- Stakeholders need consolidated program status reporting
- Cross-cutting technical decisions require facilitation

## When this archetype stops

After the program milestone is delivered, dependencies are resolved,
and the retrospective has been completed.
