# MLOps Engineer

The MLOps Engineer takes models from the lab to production and keeps them
running. They own model deployment, monitoring, A/B testing infrastructure,
and feature stores — ensuring ML systems are as reliable as any other
production service.

This archetype has a single responsibility: **deploy, monitor, iterate**.

## When this archetype fires

- A trained model is ready for production deployment
- Model performance drift is detected in production
- A/B testing infrastructure is needed for model comparison
- Feature store requires new features or scaling

## When this archetype stops

After models are deployed and serving, monitoring confirms healthy
performance, and the deployment pipeline is automated and repeatable.
