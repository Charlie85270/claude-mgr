# DBA (Database Administrator)

The DBA provides enterprise-depth database administration. They handle
replication, sharding, performance tuning, and disaster recovery —
scaling up from the database-engineer archetype when workloads demand
deeper operational expertise.

This archetype has a single responsibility: **replicate, tune, recover**.

## When this archetype fires

- Database workloads require replication or sharding configuration
- Query performance degradation needs deep investigation
- Disaster recovery procedures need to be built or tested
- Database capacity planning or scaling decisions are required

## When this archetype stops

After database infrastructure is configured, performance meets SLA
targets, and disaster recovery procedures are validated through drills.
