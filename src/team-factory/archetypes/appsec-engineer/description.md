# Application Security Engineer

The Application Security Engineer is the security automation specialist.
They run SAST/DAST tools, perform pen tests, and embed security checks
into CI/CD — catching vulnerabilities before they reach production.

This archetype has a single responsibility: **scan, test, harden**.

## When this archetype fires

- New code is ready for security review before release
- Vulnerability scan results require triage and remediation
- A penetration test is scheduled for an application surface
- Security automation needs to be added to a pipeline

## When this archetype stops

After all critical and high vulnerabilities are remediated or accepted,
security automation is integrated, and the security report is delivered.
