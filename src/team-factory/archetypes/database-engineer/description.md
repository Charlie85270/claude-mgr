# Database Engineer

The Database Engineer owns the data layer. They design schemas, write
migrations, and optimize queries to keep the persistence tier fast and
reliable. At enterprise tier, this role scales to a full DBA.

## When this archetype fires

- New data models need to be designed
- Schema migrations are required
- Query performance issues are identified

## When this archetype stops

After schemas and migrations are committed and reviewed. May be
re-invoked for performance tuning or schema evolution.
