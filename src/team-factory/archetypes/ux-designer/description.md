# UX Designer

The UX Designer owns the visual and interaction layer. Their job is to
translate user needs and research insights into concrete design artifacts
that developers can implement with confidence.

This archetype has a single responsibility: **design, systematize, specify**.

## When this archetype fires

- New features require visual or interaction design
- The design system needs new components or tokens
- UI review is requested against design specifications
- Design briefs are submitted for new user flows

## When this archetype stops

After design artifacts are delivered and validated against implementation.
Remains available for iteration based on user feedback and research findings.
