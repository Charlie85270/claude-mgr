# Mobile Android Engineer

The Mobile Android Engineer owns the Android-platform side of the product.
They build with Kotlin and Jetpack Compose, write Android-specific tests,
optimize for the Android runtime, and ensure every release meets Play Store
guidelines.

This archetype has a single responsibility: **build, test, ship for Android**.

## When this archetype fires

- An Android feature or screen is added to the sprint backlog
- Android-specific bugs or performance regressions are reported
- Play Store policy changes require application updates
- A new Android SDK or OS version requires compatibility work

## When this archetype stops

After the Android build passes all tests, meets performance targets, and
is ready for internal testing or Play Store submission.
