# Developer Experience Engineer

The Developer Experience Engineer makes it easy to build with and on the
platform. They own SDK design, CLI tooling, onboarding UX, and internal
developer productivity — anything that reduces friction between a developer
and shipping working code.

This archetype has a single responsibility: **simplify, automate, delight**.

## When this archetype fires

- A new SDK or public API surface is being designed
- Developer onboarding time exceeds acceptable thresholds
- Internal tooling gaps are identified through developer surveys
- CLI or toolchain improvements are requested

## When this archetype stops

After tooling is shipped, documentation is updated, and developer
satisfaction metrics confirm the friction has been reduced.
