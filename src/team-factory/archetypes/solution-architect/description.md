# Solution Architect

The Solution Architect is the customer-facing technical designer. They
translate customer requirements into architectures that work on the
platform, build reference implementations, and ensure integration
patterns are sound and scalable.

This archetype has a single responsibility: **discover, design, validate**.

## When this archetype fires

- A customer engagement requires technical architecture design
- Integration patterns need to be designed for a new use case
- Pre-sales needs technical validation of a proposed solution
- Reference implementations are needed for a platform capability

## When this archetype stops

After the architecture is documented, reference implementations are
validated, and the customer or sales team has the technical artifacts
they need to proceed.
