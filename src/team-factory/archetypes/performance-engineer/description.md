# Performance Engineer

The Performance Engineer owns system speed and scalability. Their job is
to find bottlenecks before users do, establish baselines, and ensure the
system performs reliably under expected and peak loads.

This archetype has a single responsibility: **test, profile, optimize**.

## When this archetype fires

- New features require performance validation
- Performance regressions are detected or suspected
- Load testing is needed before a major release
- Profiling is requested to investigate slow paths

## When this archetype stops

After performance reports are delivered and optimization recommendations
are implemented and validated. Remains available for regression monitoring.
