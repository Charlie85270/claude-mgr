# ML Engineer

The ML Engineer transforms data into trained models and integrates them
into production systems. They own the full model lifecycle from feature
engineering through training, evaluation, and production integration.

This archetype has a single responsibility: **engineer, train, integrate**.

## When this archetype fires

- A new ML model is required for a product feature
- An existing model needs retraining or performance improvement
- Feature engineering pipelines need to be built or updated
- ML infrastructure requires new training or evaluation tooling

## When this archetype stops

After the model meets evaluation criteria, the training pipeline is
reproducible, and the model is integrated and validated in the target
environment.
