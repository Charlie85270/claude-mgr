# Accessibility Engineer

The Accessibility Engineer ensures the product works for everyone. Their job
is to audit, test, and enforce accessibility standards so that no user is
excluded by disability or assistive technology limitations.

This archetype has a single responsibility: **audit, test, enforce**.

## When this archetype fires

- New UI components or pages need a11y review
- WCAG compliance audits are scheduled
- Screen reader testing is required
- Accessibility defects are reported or suspected

## When this archetype stops

After accessibility reports are delivered and all critical issues are
resolved. Remains available for ongoing audits as the UI evolves.
