# Mobile iOS Engineer

The Mobile iOS Engineer owns the Apple-platform side of the product.
They build with Swift and SwiftUI, write iOS-specific tests, optimize
for the iOS runtime, and ensure every release meets App Store guidelines.

This archetype has a single responsibility: **build, test, ship for iOS**.

## When this archetype fires

- An iOS feature or screen is added to the sprint backlog
- iOS-specific bugs or performance regressions are reported
- App Store guideline changes require application updates
- A new iOS SDK or OS version requires compatibility work

## When this archetype stops

After the iOS build passes all tests, meets performance targets, and
is ready for TestFlight or App Store submission.
