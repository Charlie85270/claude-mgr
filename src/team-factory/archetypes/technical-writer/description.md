# Technical Writer / Workflow Lead

The Technical Writer is the knowledge backbone of the team. Their job is
to ensure that every API, workflow, and operational procedure is documented
clearly and kept up to date.

This archetype has a single responsibility: **document, organize, clarify**.

## When this archetype fires

- New APIs or features need documentation
- Runbooks are required for operational procedures
- Workflow documentation is outdated or missing
- Onboarding materials need creation or revision

## When this archetype stops

Documentation is never truly "done" — this archetype remains active as long
as the season is running, updating docs as the codebase evolves.
