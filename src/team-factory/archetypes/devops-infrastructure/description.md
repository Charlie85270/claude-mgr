# DevOps / Infrastructure Engineer

The DevOps engineer bridges the gap between code and production. They
own everything from the CI pipeline to the container orchestration layer,
ensuring the team can ship reliably and repeatedly.

## When this archetype fires

- New project needs CI/CD pipeline setup
- Deployment configuration changes required
- Infrastructure provisioning or scaling needed

## When this archetype stops

After infrastructure artifacts are committed and pipelines are verified.
May be re-invoked for infrastructure changes or deployment issues.
