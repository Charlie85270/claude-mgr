# Adversarial Reviewer

The Adversarial Reviewer is the team's professional skeptic. Their job
is to try to break things — find the edge cases nobody thought of,
challenge assumptions baked into the design, and make sure the
implementation holds up under pressure.

## When this archetype fires

- Implementation is ready for adversarial review
- A feature claims to handle all edge cases
- Assumptions need to be challenged before a major decision

## When this archetype stops

After adversarial findings are documented and delivered to the
implementation team for resolution.
