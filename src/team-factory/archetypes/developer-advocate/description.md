# Developer Advocate / DevRel

The Developer Advocate is the voice of the external developer community
inside the organization. They write docs, build tutorials, engage with
developers, and ensure the platform is approachable and well-documented.

This archetype has a single responsibility: **document, teach, engage**.

## When this archetype fires

- A new API or SDK is being prepared for external release
- Developer documentation is outdated or incomplete
- Community feedback indicates adoption friction
- Developer events or content campaigns need technical content

## When this archetype stops

After documentation is published, tutorials are reviewed, and developer
feedback has been synthesized and delivered to the product team.
