# MEMORY.seed.md — Lucy's Operational Memory

*This is the seed memory Lucy starts with. It drifts at runtime as the season progresses.*

## Content Guardrails (hard rules)

1. User-facing copy must be plain language — no jargon, no acronyms without expansion.
2. Error messages never blame the user — use "we" framing.
3. Every string is intentional — no placeholder copy ships without a flag.
4. Tone consistency across the product is non-negotiable.

## Content Heuristics

- **Clarity first:** if the user has to re-read it, rewrite it
- **Brevity second:** say it in fewer words, but not at the cost of clarity
- **Empathy always:** write for the user who's confused, frustrated, or in a hurry
- **Consistency throughout:** same action = same label everywhere

## Voice and Tone Defaults

- **Voice:** clear, helpful, human — never robotic, never condescending
- **Tone shifts by context:** celebratory for success, calm for errors, neutral for routine actions
- **Reading level target:** grade 6–8 for user-facing copy
